JARVIS WINDOWS 3.1 — ҮШ ТІЛ, ЖҰМЫС ҚҰРАЛДАРЫ ЖӘНЕ БІРНЕШЕ ЖИ

ІСКЕ ҚОСУ ЖӘНЕ ЖАҢАРТУ
1. Ескі JARVIS серверінің қара терезесін жабыңыз.
2. Архивті толық шығарыңыз. Жаңартқанда барлық бағдарлама файлдарын бұрынғы
   JARVIS бумасына ауыстырыңыз; тек index.html ауыстыру жеткіліксіз.
3. Жергілікті ai_config.local.json, apps.local.json және JARVIS_Workspace
   өз бумасында қалады. Архивтің ішінде сіздің кілттеріңіз жоқ.
4. Python 3.11 немесе жаңасын орнатыңыз: https://www.python.org/downloads/windows/
   Add python.exe to PATH белгісін қойыңыз.
5. START.bat ашыңыз. Алғашқы іске қосуда psutil модулін орнатуға интернет керек.
6. Басқару беті браузерде ашылады. Сервер терезесін ашық қалдырыңыз.
   Тоқтату үшін Ctrl+C басыңыз. 127.0.0.1 сілтемесі тек осы компьютерге тиесілі.

ЕКІ ТӘСІЛМЕН ЖИ ПАЙДАЛАНУ
А. ЖИ сайты браузерде ашылады.
«Gemini аш», «ChatGPT аш», «Perplexity аш», «Copilot аш», «Claude аш».
Орысша: «Открой Gemini». Ағылшынша: «Open Gemini».
Сайт ашылған соң аккаунтқа кіріп, сұрақты сол сайтта өзіңіз бересіз.
JARVIS бұл сайттарға сұрақты автоматты енгізбейді және жауабын көшірмейді.
Сайттың кіру талаптары мен лимиттері бөлек қолданылады.

Ә. Жауап JARVIS ішінде API арқылы алынады.
Жоғарыдағы «ЖИ» өрісінен OpenAI, Gemini немесе Perplexity таңдаңыз.
Таңдалған платформаға сұрақ және соңғы алты сұрақ-жауап жіберіледі.
ЖИ ауыстырылғанда әңгіме тазарады; басқа платформаға бұрынғы контекст
автоматты түрде берілмейді. Қате шықса, сұрақ басқа платформаға ауыстырылмайды.

API КІЛТТЕРІН ҚОСУ
1. SETUP_AI.bat ашыңыз.
2. OpenAI / Gemini / Perplexity платформасын таңдаңыз.
3. «Кілт алу бетін ашу» арқылы сол қызметтің API баптауына өтіңіз.
   OpenAI: https://platform.openai.com/api-keys
   Gemini: https://aistudio.google.com/apikey
   Perplexity: https://www.perplexity.ai/account/api
4. Сол платформаның кілтін жасырын өріске Ctrl+V арқылы қойыңыз.
5. Қолжетімді модель атауын тексеріп, «Баптауды сақтау» басыңыз.
6. Басқа платформаның кілтін қосу үшін оны тізімнен таңдап, қайталаңыз.
   Кілт өрісі бос болса, сол платформада бұрын сақталған кілт қалады.
7. JARVIS бетінен осы платформаны таңдаңыз. Алғашқы сұрақ байланысты тексереді.

Бұрынғы OpenAI кілті мен моделі сақталады. Кілттер тек компьютердегі
ai_config.local.json ішінде болады, браузерге қайтарылмайды. .gitignore
оларды Git-тен шығарады. Кілтті чатқа, GitHub-қа немесе скриншотқа жібермеңіз.
Осы компьютердің файлдарын оқи алатын адам жергілікті кілт файлын оқи алады.
OPENAI_API_KEY / OPENAI_MODEL, GEMINI_API_KEY / GEMINI_MODEL,
PERPLEXITY_API_KEY / PERPLEXITY_MODEL орта айнымалылары файлдан басым.
API қызметі, модель және интернеттен іздеу үшін тариф пен лимиттер қолданылады.
Жазылым мен API балансы бірдей деп қабылдамаңыз. Қолжетімділікті қызметтен тексеріңіз.

ИНТЕРНЕТТЕН ІЗДЕУ ЖӘНЕ СІЛТЕМЕЛЕР
«Интернеттен іздеу» қосқышын қосып, сұрақ қойыңыз.
OpenAI — Responses web_search; Gemini — Google Search;
Perplexity — Agent API web_search құралын қолданады.
Құрал қолжетімді болса, модель іздеу қажеттігін өзі анықтайды.
Қосқыштың қосылуы әр сұрақта міндетті іздеу жасалды дегенді білдірмейді.
Нәтиже астында дереккөздің қайтарылғаны көрсетіледі. Сілтемелер жауап
ішінде және бөлек тізімде басылады. Gemini іздеу ұсыныстары бөлек қорғалған
блокта көрсетіледі. Модель іздеу құралын қолдамаса, баптау қатесі беріледі.
Іздеу өшірулі болса, веб құрал сұрауға қосылмайды. Жауап ағымдағы деректерді
білдіреді деп автоматты қабылдамаңыз. Көлем шегінен толық аяқталмаған жауап белгіленеді.

ҮШ ТІЛ ЖӘНЕ ДАУЫС
«Сөйлесу тілі»: Қазақша / Русский / English.
Микрофон тілі, жергілікті жауап, AI нұсқауы және дыбыстау тілі бірге ауысады.
Таңдалған тіл мен ЖИ осы браузерде сақталады. «Дауысты сынау» қолданыңыз.
Дауыс тізімінде тек таңдалған тілдегі қолжетімді дауыстар көрсетіледі.
Қазақша дауыс бар-жоғы құрылғы мен браузерге байланысты. Тілді орнату
әрқашан Text-to-Speech дауысын орнату деген сөз емес. Сәйкес дауыс жоқ
болса, басқа тілмен алмастырылмайды, мәтін және ескерту көрсетіледі.
Chrome/Edge қолданыңыз. Микрофонға рұқсат беріңіз. Бір пәрменнен кейін
тыңдау тоқтайды. Браузер тану сервисі интернетті қажет етуі және дыбысты
сыртқы сервиске жіберуі мүмкін. Браузер 800, Windows SAPI 300 таңбаны оқиды.
Windows SAPI және браузер дауыстарының тізімдері әртүрлі болуы мүмкін.

АНИМАЦИЯ
Жасыл — тыңдау; сары — өңдеу; көк — дыбыстау; қызғылт — қате.

Жүйедегі қозғалысты азайту параметрі де ескеріледі.

РЕЖИМДЕР

Тек AI сұхбат: мәтіндік және дауыстық сұрақтар ЖИ-ға беріледі.
Тек компьютер пәрмендері: таныс жергілікті әрекеттер орындалады.
Жылдам батырмалар кез келген режимде жергілікті әрекетті орындайды.

сақталады; бетті жаңарту, «Жаңа әңгіме» не ЖИ ауыстыру оны тазартады.

ЖЕКЕ ҚОСЫМШАЛАРДЫ ТІРКЕУ
SETUP_APPS.bat ашыңыз. Бағдарлама атауын және осы компьютердегі .exe
файлын таңдаңыз. Үтірмен 1–5 бірегей шақыру атауын енгізіңіз: телеграм, telegram.
«Бағдарламаны қосу», содан соң JARVIS-та «Тізімді жаңарту» басыңыз.
Ең көбі 20 жеке бағдарлама. Әр компьютерде жолды бөлек баптау керек.
Store қолданбасының .exe жолы қолжетімсіз болса, оны тіркеу мүмкін болмауы мүмкін.
Баптау apps.local.json ішінде қалады, GitHub-қа жіберілмейді.

ЖҰМЫС ФАЙЛДАРЫ
Бумалар, жазбалар және есептер JARVIS_Workspace ішінде жасалады.
Бар файл қайта жазылмайды; бар бумаға қайта құру қатесі беріледі.
Іздеу тек атау бойынша; файлдың ішін оқымайды және оны AI-ға жібермейді.
Аймақ: жұмыс бумасы, Documents, Downloads, Desktop. Шектер: 30 нәтиже,
5 ішкі деңгей, 3 секунд және қарап шығу саны. Нәтиже толық болмауы мүмкін.
Табылған файлдың орналасқан бумасын нәтижедегі батырмамен ашыңыз.
Толық есеп ОЖ, CPU, RAM, диск, жүктелу уақыты және RAM бойынша 10 процесті жазады;
бұл аппараттық ақаудың толық диагностикасы немесе автоматты жөндеу емес.
«Сабаққа дайындал» Lesson бумасын, Materials/Tasks/Results бумаларын және
Lesson_notes.txt үлгісін жасап, Word пен браузерді ашады.
Жергілікті құралдар мен ЖИ сайттарын ашуға API кілті қажет емес.

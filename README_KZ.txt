JARVIS WINDOWS 3.0 — AI СҰХБАТ

ІСКЕ ҚОСУ
1. Ескі JARVIS қара терезесін жабыңыз. Архивті жаңа бумаға толық шығарыңыз.
2. Python 3.11 немесе жаңасын орнатыңыз: https://www.python.org/downloads/windows/
   Add python.exe to PATH белгісін қойыңыз.
3. START.bat іске қосыңыз. Алғашқы іске қосуға интернет қажет.
4. Қара терезені ашық қалдырыңыз. Басқару беті браузерде ашылады.

AI ҚОСУ
1. https://platform.openai.com/api-keys бетінде OpenAI API кілтін жасаңыз.
2. API қолдану шығыны болады; API балансы мен пайдалану лимиттерін тексеріңіз.
3. JARVIS бумасынан SETUP_AI.bat ашыңыз. Кілт енгізетін шағын терезе ашылады.
4. Кілт өрісін басып, Ctrl+V арқылы қойыңыз. Кілт таңбалары жасырын көрсетіледі.
5. Модельді gpt-5-mini күйінде қалдырып, «Кілтті сақтау» батырмасын басыңыз.
   «Кілт сақталды» хабарын көргенде баптау аяқталды. Консольдегі «Press any key»
   жолы тек терезені жабу үшін көрсетіледі. Консольдік режимде кілт көрінбейді:
   қою үшін оң жақ батырманы басып, Enter басыңыз.
6. JARVIS бетін жаңартыңыз. AI кілті бапталған деген хабар шығады.
7. Сұрақ енгізіңіз: «Маған Word тақырыбына 5 сұрақ құрастыр».
8. Нақты байланыс алғашқы AI сұрағында тексеріледі.

Кілт тек ai_config.local.json файлында осы компьютерде сақталады.
Осы компьютердегі файлдарға кіре алатын адам кілтті оқи алады.
Кілтті чатқа, GitHub-қа немесе скриншотқа жібермеңіз.
.gitignore бұл файлды Git-тен шығарады. Кілтті жаңарту үшін SETUP_AI.bat қайта ашыңыз.
OPENAI_API_KEY және OPENAI_MODEL орта айнымалылары да қолдау табады; олар файлдағы баптаудан басым.

РЕЖИМДЕР
Авто: таныс жергілікті пәрмендерді орындайды, басқа сұрақтарды AI-ға жібереді.
Тек AI сұхбат: барлық мәтіндік және дауыстық сұрақтарды AI-ға жібереді.
Тек компьютер пәрмендері: тек таныс жергілікті пәрмендерді орындайды, AI шақырылмайды.
Оң жақтағы жылдам батырмалар кез келген режимде жергілікті пәрменді орындайды.
AI сұхбаты өздігінен компьютерде әрекет орындамайды.
AI жауабы таңдалған сөйлесу тілінде беріледі; аудару сұрағы бөлек ескеріледі.
Соңғы алты сұрақ-жауап көлем шегімен келесі сұраққа қосылады.
Сұрақтар мен осы контекст OpenAI сервисіне жіберіледі.
Тарих тек бет жадында сақталады. «Жаңа әңгіме» немесе бетті жаңарту оны тазартады.
Бұл нұсқада интернеттен іздеу және компьютердегі файлдарды автоматты оқу қосылмаған.

МИКРОФОН ЖӘНЕ ДАУЫС
Chrome/Edge қолданыңыз. Мекенжай http://127.0.0.1:... болуы керек.
Тыңдау батырмасын басып, микрофонға рұқсат беріңіз. Бір пәрменнен кейін тыңдау тоқтайды.
Сөйлесу тілін қазақша, орысша немесе ағылшынша таңдаңыз.
Қазақша тану браузер сервисінің қолдауына байланысты; танылмаса, орысша не мәтін енгізуді қолданыңыз.
Браузердің тану сервисі интернетті қажет етуі және дыбысты серверге жіберуі мүмкін.
Дауыстық жауап браузердегі дауысты қолданады: жауаптың алғашқы 800 таңбасы оқылады.
Windows дауысы SAPI арқылы алғашқы 300 таңбаны оқиды; PowerShell қолданылмайды.
Windows дауысы істемесе, осы батырма браузердің дыбыстауына ауысады.
Пәрмен бермей Windows дауысы батырмасын бассаңыз, таңдалған тілде сынақ оқылады.
Қазақша дауыс орнатылмаса, дыбыстау сапасы төмен болуы мүмкін.

АНИМАЦИЯ
Орталықтағы JARVIS бейнесі нақты әрекет күйін көрсетеді:
жасыл — микрофон тыңдауы; сары — сұрау орындалуы; көк — дыбыстау;
қызғылт — қате; жауап дайын болғанда қысқа жарық анимациясы беріледі.
Толқындар дыбыстың нақты қаттылығын өлшемейді, жұмыс күйін бейнелейді.
«Анимация: қосулы» батырмасымен қозғалысты өшіруге болады.
Жүйедегі қозғалысты азайту параметрі де ескеріледі.
Анимация үшін API кілті қажет емес; AI сұхбатқа API баптауы қажет.

ҮШ ТІЛДЕ СӨЙЛЕСУ
«Сөйлесу тілі» өрісінен Қазақша / Русский / English таңдаңыз.
Микрофон тілі, жергілікті жауап, AI нұсқауы және дыбыстау тілі бірге ауысады.
Тіл таңдауы осы браузерде сақталады. «Дауысты сынау» арқылы тексеріңіз.
Дауыс тізімінде тек таңдалған тілдегі дауыстар көрсетіледі.
Егер сәйкес дауыс жоқ болса, басқа тілмен алмастырылмайды: мәтін көрсетіліп,
ескерту беріледі. Қазақша дауыстың болуы құрылғы мен браузерге байланысты.
Тілді жай қосу жеткіліксіз болуы мүмкін: сол тілдің Text-to-Speech дауысы керек.
Windows SAPI және браузер дауыстарының тізімдері әртүрлі болуы мүмкін.
Жауаптың алғашқы 800 таңбасын браузер, 300 таңбасын Windows дауысы оқиды.
Тек жергілікті пәрмен мен дауыс сынағына API қажет емес. AI сұрағына API
кілті, рұқсат және жеткілікті баланс қажет.

ЖАҢА ҚОСЫМШАЛАРДЫ ТІРКЕУ
1. JARVIS бумасынан SETUP_APPS.bat ашыңыз.
2. Бағдарлама атауын енгізіңіз, «Файлды таңдау» арқылы оның .exe файлын таңдаңыз.
3. Үтір арқылы 1–5 шақыру атауын жазыңыз. Мысалы: телеграм, telegram.
4. «Бағдарламаны қосу» басыңыз. JARVIS бетіндегі «Тізімді жаңарту» басыңыз.
5. «Телеграм аш» немесе «Open Telegram» деңіз.
Ең көбі 20 жеке бағдарлама тіркеледі. Әр компьютерде жолды бөлек баптайсыз.
Microsoft Store қолданбасының .exe файлына тікелей жол қолжетімсіз болса,
оны бұл тіркеу терезесі арқылы қосу мүмкін болмауы мүмкін.
Қосымша баптау apps.local.json ішінде қалады; GitHub-қа жіберілмейді.
Файл бүлінсе, оны сақтық атауға ауыстырып, SETUP_APPS.bat арқылы қайта тіркеңіз.

ФАЙЛДАР МЕН ЖҰМЫС БУМАСЫ
Жаңа бумалар, жазбалар және есептер JARVIS_Workspace ішінде жасалады.
Бар файл қайта жазылмайды; бар бума атауына қайта құру пәрмені қате береді.
Файл іздеу тек атаулар бойынша жүреді, мазмұнды оқымайды және AI-ға жібермейді.
Іздеу аймағы: JARVIS_Workspace, Documents, Downloads, Desktop.
Ең көбі 30 нәтиже, 5 деңгей, 3 секунд және қарап шығу саны бойынша шек бар.
«Шектелді» белгісі болса, нақты файл атауымен қайта іздеңіз.
Табылған файлдың бумасын нәтижедегі батырмамен ашуға болады.

ТОЛЫҚ ЕСЕП ЖӘНЕ САБАҚҚА ДАЙЫНДАЛУ
Толық есеп: ОЖ, архитектура, процессор ядролары мен ағымдағы жүктеме,
жедел жад, дискідегі бос орын, соңғы жүктелу уақыты және RAM бойынша
ең көп пайдаланатын 10 процесті мәтіндік файлға сақтайды.
Бұл толық аппараттық диагностика емес; есеп автоматты жөндеу жасамайды.
«Сабаққа дайындал» бірегей Lesson бумасын, Materials/Tasks/Results ішкі
бумаларын және Lesson_notes.txt үлгісін жасап, Word пен браузерді ашады.
Word жоқ болса да, жасалған бумалар сақталады, хабарда іске қосу қатесі беріледі.
Word-та мәтін теру, экранды басу және интернетте әрекет жасау бұл нұсқада
автоматтандырылмаған. Тек нақты көрсетілген жұмыс сценарийлері орындалады.
Жергілікті құралдар үшін API кілті қажет емес. «Тек AI» режиміндегі мәтін
сұраққа AI жауап береді; жергілікті әрекет үшін «Авто» не «Тек пәрмендер» таңдаңыз.
